## 0.0.0 (notes written by hand before the changelog was generated)

- Project plan, design documents and RFC drafts 0001 to 0006.
- Repository tooling: license, formatter and linter configuration, pre-commit hooks, GitHub
  templates, labels and pull-request checks.
- `lagrange_core` package with simulation time types.
- `lagrange_proto` package: viewer protocol messages (`lagrange.viewer.v1`) with generated C++
  and Python code. RFC 0003 accepted.
- Protocol framing: `FrameReader` and `appendFrame` for length-prefixed frames, with a fuzz
  target.
- `lagrange_cmake` package with the shared compile options.
- Protocol transport: non-blocking `Connection` and `Listener` over Unix sockets and TCP,
  file-descriptor passing, `Endpoint` parsing and reconnect `Backoff`.
- Shared-memory fast path: `ShmArena` (sealed memfd ring) and `ShmReader` with generation and
  content-hash checks.
- `lagrange_mock_server` package: asyncio replay server (play, pause, step, seek, speed,
  full/min-max/stride subscriptions), MCAP recording format, a synthetic sample recording, and
  a protocol conformance client (`--check`).
- Golden protocol frames read identically by the C++ and Python decoders.
- `lagrange_gpu` package: Vulkan device layer with capability tiers (0 CPU, 1 raster GPU,
  2 hardware ray tracing), Slang shader build support and the `lagrange_gpu_info` tool.
- `imgui_vendor` package: Dear ImGui docking branch with the SDL3 and Vulkan backends.
- `lagrange_viewer`: the first window. Dockable Viewport, Scene, Inspector and Timeline
  panels; protocol client with reconnect; orbit camera; headless mode with screenshots.
  RFC 0004 and RFC 0006 accepted.
- Waveform scopes: signal catalog and name-based subscriptions in the viewer client, a
  lock-free `ScopeBuffer` with per-pixel min/max decimation, and a Scope panel (ImPlot) with
  one stacked plot per unit, freeze, window lengths from 20 ms to 30 s and a dropped-sample
  counter. ImPlot v1.0 added to `imgui_vendor`.
- Opening your own robot: the mock server imports URDF and xacro files (links, joints at
  zero, box/cylinder/sphere and STL/OBJ/DAE visuals, material colours) and reports what it
  could not use. In the viewer: File > Open, Ctrl+O, drag and drop, or `--open`. Recordings
  (`.mcap`) open the same way. `assets/robots/primitives_arm` is a small test robot.

### Changed

- CI builds only when code changed, runs the protocol checks only when the protocol changed,
  and fuzzes nightly instead of on every pull request.
