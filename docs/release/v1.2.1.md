# Lagrange v1.2.1: one command to install (release notes)

v1.2.1 is a packaging release on the stable 1.x line. The simulator is the same as v1.2.0.
What changes is how you get it: on Ubuntu 26.04 (amd64), one command now installs ROS 2 Lyrical
and Lagrange from the release's packages, with nothing to build.

**Status:** released on 2026-11-11 as `v1.2.1`, on the owner's request. Documentation:
<https://open-physical-systems.github.io/Lagrange/>.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Open-Physical-Systems/Lagrange/main/packaging/install.sh | bash
source /opt/ros/lyrical/setup.bash
lagrange amr
```

- **`packaging/install.sh`:**
  - Installs ROS 2 Lyrical when it is missing.
  - Downloads `lagrange-VERSION-debs-amd64.tar` from the release and checks it against its
    `.sha256`.
  - Installs the debs with apt and the two pip pins (`mcap`, `coacd`).
  - Checks that `lagrange` starts.
  - It asks before installing, also when piped from curl. Options: `LAGRANGE_VERSION`,
    `LAGRANGE_DEBS=DIR` (debs you built), `LAGRANGE_YES=1`.
- **The release carries the debs:** 51 `ros-lyrical-*` packages in one 35 MB archive, made by
  `packaging/debs/release_archive.sh`.
- **The debs build in parallel.** bloom's rules use debhelper compat 9, where `dh` built serially.
  With `--parallel`, OpenUSD builds with all the jobs asked for; the full set takes under an hour.
- **Docs:** the install guide and the front page start from the one-liner. Building from source,
  your own debs and the container are still there.

## Upgrading from 1.2.0

Nothing changes in files, plugins, profiles or recordings. If you installed 1.2.0 from the
archive, run the installer again to move to 1.2.1. A source build only needs `git pull`.

## Checked

- **The debs:** `packaging/test_install.sh` passes on the built debs: CLI, a Python run,
  determinism, a streamed world, the migration tools and the world builder.
- **The installer, in a bare `ubuntu:resolute` container:**
  - from the local debs and from the release download;
  - it installs ROS 2 Lyrical from nothing;
  - `lagrange info --version`, `lagrange heat` and a Python simulation then run.
